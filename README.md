`supabase_setup.sql`, `migration_v2.sql`, `migration_v3.sql`, `migration_v4.sql`.

## Mise en ligne sur GitHub Pages
1. Crée un dépôt GitHub public et envoie-y tout ce dossier en gardant les sous-dossiers.
2. Ouvre `js/config.js` et renseigne l'URL Supabase et la clé publique (anon / publishable).
3. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
4. Adresse : `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/` ; écran public : `.../#ecran`.
